# DugnadsHub - Crossplatform Exam
 
**Course:** Crossplatform Development (7.5 ECTS)  
**Institution:** Kristiania University College  
**Tech:** React Native, TypeScript, Firebase  
**Team:** Group project
 
***DugnadsHub is a crossplatform app where the main goal is organising "dugnad".***    
Dugnad is a long-standing Norwegian custom where neighbors and community members pitch in together on unpaid, voluntary tasks like cleaning shared areas, maintenance work, or organizing local events. DugnadHub brings this tradition into an app: users can browse upcoming dugnader and sign up to help, while organizers can create and manage their own events.

## Firebase
 
The app's backend runs entirely on Firebase. Firebase Authentication handles sign-in (email/password and Google), Firestore stores dugnad listings, sign-ups, and comments, and Firebase Storage holds the images users attach to each event.
